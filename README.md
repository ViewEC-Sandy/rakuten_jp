# 日本 EC Dashboard V2

這是一個部署於 GitHub Pages 的純前端 CSV 分析儀表板。

## 本版本功能

- 左側分區選單
- 營運總覽
- 銷售分析
- 商品銷售表
- 店鋪／平台比較
- 廣告分析
- CSV 匯入管理
- 不同格式 CSV 欄位對應
- 欄位模板儲存
- 可連續匯入多個 CSV 並合併分析
- 可選擇保留舊資料或清除後重新分析
- 不包含 API 自動匯入

## 使用方式

1. 點選「CSV 匯入」。
2. 上傳 CSV。
3. 在「欄位對應」選擇正確欄位。
4. 若要把資料合併到現有資料，按「加入分析資料」。
5. 若要清除舊資料，按「清除舊資料後分析」。
6. 到各分區查看分析結果。

## 不同格式 CSV

不同平台的 CSV 欄位名稱可以不同。只要在匯入時對應到下列標準欄位即可：

必要：
- 日期
- 訂單編號
- 商品名稱
- 數量
- 營收

選用：
- SKU／商品管理編號
- 平台
- 店鋪
- 廣告費
- 廣告營收

## 欄位模板

在完成欄位對應後，到「欄位模板」輸入名稱並儲存。

例如：
- 楽天注文CSV
- Amazon訂單
- Shopify銷售資料

模板會儲存在目前瀏覽器的 localStorage 中，不會上傳到 GitHub。

## GitHub 更新方式

1. 解壓縮 ZIP。
2. 回到 Repository。
3. 點 `Add file` → `Upload files`。
4. 將以下檔案上傳並覆蓋：
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
5. 點 `Commit changes`。
6. 等待 GitHub Pages 更新。

## 資料安全

CSV 只在使用者的瀏覽器內處理。重新整理頁面後，本次匯入資料會消失；欄位模板會保留在該瀏覽器中。
