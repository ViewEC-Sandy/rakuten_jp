# Japan EC Dashboard V10.3

V10.3 以 V10.1 為基礎，整合 V10.2 的趨勢比較重構，並加入管理者分析與匯出功能。

## 主要更新

- 營收趨勢改為同期月份／季度／年度對齊，不再把不同年份放在不同 X 軸位置。
- 自動模式：只顯示本期或比較期實際有資料的月份／季度。
- 圖例顯示實際年份；缺少資料使用 null，不以 0 補值。
- 圖表粒度可切換：月、季、年。
- KPI 卡片支援點擊鑽取至平台或商品分析頁。
- 商品銷售排行擴充為 Top 20。
- 新增專案營收 Top 10 橫條圖。
- 新增每日營收熱力圖。
- 新增目前查詢結果 CSV 匯出。
- 新增瀏覽器列印／另存 PDF。
- 保留 V10.1：Rakuten 銷售額扣除「店舗発行クーポン利用額」。

## 部署

將所有檔案上傳至 GitHub Pages 專案，並確認 `firebase-config.js` 已填入正確 Firebase 設定。
